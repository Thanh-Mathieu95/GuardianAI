# Product

## Platform

web

## Users

People walking alone at night, their invited contacts, consenting partner venues and demo judges. Vietnamese and English.

## Product Purpose

Turn a request for help into verified human commitments and a clear next action, preserve a reviewable record. Never guarantee safety.

## Operating Context

Three isolated scopes: `/team` for Support profiles and real teammates using simulated locations, `/demo` for scripted fictional participants, `/walk` and `/phone` for live GPS. `/join/token` opens a recipient's own role. Real voice uses OpenAI with consent. Pages must stay open. No native push or emergency dispatch.

## Capabilities and Constraints

The in-app call coordinator maintains separate recipient conversations, parallel delivery limits, expanding partner discovery and sourced case files. Support profiles hold the actual invited names, roles, links and readiness that drive SOS in TEAM. TEAM uses real consenting roleplayers and mock venue locations; replies are never scripted. Late arrivals and late call consent join the active incident. Existing owner-authenticated invitations created in the old DEMO workspace can be recovered into TEAM with their original tokens intact. DEMO uses only fictional participants behind explicit run controls; its manual SOS and invitation controls direct people to TEAM. LIVE requires current GPS and joined, consenting recipients. The AI companion can activate SOS with consent; route acceptance and emergency dialing remain user actions. No phone gateway is used. See docs/IN-APP-COORDINATION.md.
Next 16, React 19, TypeScript, Zod, MapLibre, SQLite locally, optional Postgres for cloud. Durable state before success responses. No fabricated live routes. Real API failures remain visible. API key stays server-side.

## Brand Commitments

Guardian AI uses a dark command center and an interactive phone simulator: cyan confirmed support, blue references, amber tentative offers and red urgent states. The landing page retains its paper presentation. Clear source labels and visible VI/EN controls.

## Accessibility & Inclusion

One-handed controls, 44px targets, high contrast, reduced motion, VI/EN switching. Original evidence remains untranslated.
